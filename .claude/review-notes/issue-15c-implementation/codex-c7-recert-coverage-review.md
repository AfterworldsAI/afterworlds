1. **P1 — creature template authority is absent from operation certification.** Defect class: merge-blocking certification/override boundary. Disposition: in-scope implementation. `capability.py:507-549` fingerprints fixed checks, shared procedures, conditions, and, for `weapon_attack`, equipment weapon/armor components. It does not include the effective creature template. `certify` compares only that fingerprint (`:570-609`). Yet `creature_attacks.py:190-235,769-809` reads that template's attack and Multiattack facts; `creature_effects.py:265-341` reads its save/effect and usage facts; `defense.py:239-306,317-339` reads target AC, responses, and immunities. Cross-binding checks in `creature_attacks.py:385-395`, `creature_effects.py:392-399`, and `attacks.py:550-562` compare the same incomplete shared fingerprint. Thus an effective override can change an attack bonus, damage, Multiattack, target AC, resistance, or immunity while the operation remains certified and the two bindings appear to agree. The recert note's new hashes and `recert/governing_diff.py:47-60` do not close this: that script calls `_governing` only in its default fixed-DC mode. Include every operation/subject's applicable template components in exact certification, distinguishing shared-procedure agreement from subject-specific template authority. Prove a relevant template override invalidates affected certification or is separately certified, and an unchanged template still works across compatible bindings.

2. **P1 — source-defined creature attack clauses are silently dropped while the attack runs.** Defect class: merge-blocking source-constraint and false-coverage defect. Disposition: in-scope implementation against the already accepted C5 source; no new candidate is needed for the cited facts. C5 capability marks Allosaurus Claws `supported` and executable (`candidate-c5/capability.json:12-41`). The accepted successor has a simple `creature_attack` with `hit_effect: null`, followed by same-entry typed `clause_predicate` (Large or smaller, 30-foot approach), `clause_condition` (Prone), and `clause_follow_up_attack` (Bite) at `srd-5-2-1-corpus-8781d4e0-a3b-15c.json:308437-308529`. The executor selects only `CreatureAttackFact` (`creature_attacks.py:190-235`), prepares only `fact.hit_effect` (`:526-544`), and returns no rider when that field is null (`:616-624`); it never reads clause facts. A qualifying Claws hit therefore deals damage while omitting the printed Prone and optional linked Bite. A bounded static comparison found ten C5-positive attack entries with typed clauses, including this example. Execute and validate applicable clauses with source-bound inputs and linked resolution, or refuse before dice until each admitted shape is complete. Do not count the current roll-only path as positive coverage. Regression proof should include a qualifying and a nonqualifying Claws hit plus linked Bite behavior.
